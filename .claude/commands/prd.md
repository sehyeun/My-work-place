# /prd 슬래시 커맨드

사용자가 `/prd` 또는 `/prd <주제>`를 입력하면, **반드시** `prd-writer` 스킬을 호출하여 작업을 시작하세요.

## 동작 규칙

1. `prd-writer` 스킬의 `SKILL.md`에 정의된 워크플로우를 그대로 따릅니다. Step 0부터 시작.
2. 사용자가 `/prd` 뒤에 텍스트를 적었다면 그것을 PRD의 잠정 주제로 사용하되, 인터뷰는 건너뛰지 마세요.
3. 만약 사용자가 명시적으로 "인터뷰 짧게", "빠르게" 등을 요청해도 다음 핵심 질문은 반드시 진행:
   - 사용자/페르소나
   - 문제와 현재 해결 방식
   - Non-goal
   - 성공 측정 (또는 `🟡 [확인 필요]`)
4. 최종 저장 위치: `docs/prd/YYYY-MM-DD-<slug>.md`

## 출력 톤

- 한국어 기본
- `.claude/CLAUDE.md`의 프로젝트 규칙 준수
- `🔸 [추정]`, `🟡 [확인 필요]` 마킹 적극 활용
