## 배경 / 목적

Phase 0 UI 목업(커밋 `70fdf6e`)은 **초기 가정**(구글 OAuth 로그인, 사용자별 GitHub 리포 선택 등)으로 만들어졌습니다. 이후 Stage 1 시나리오 컨펌(2026-05-24)에서 인증·리포·알림·편집 정책이 바뀌면서 목업과 확정 결정 사이에 차이가 생겼습니다.

이 문서는 그 차이를 빠짐없이 기록해, Stage 2 와이어프레임을 그릴 때 "무엇을 바꿔 그려야 하는지"의 체크리스트로 쓰기 위한 것입니다. **이 시점에 목업 코드는 고치지 않습니다** — 어차피 Stage 2에서 화면을 재설계하므로 중복 작업을 피합니다.

## Stage 2 와이어프레임 반영 체크리스트

와이어프레임 작성 시 아래를 화면으로 반영하면 본 불일치가 해소됩니다.

- [ ] **로그인 화면**: 구글 버튼 → 이메일/패스워드 폼 (A1, A2)
- [ ] **가입 화면 신설**: 초대 토큰 진입 → 이메일(read-only)/PW/이름/부서 → 자동 로그인 → 대시보드 (B1)
- [ ] **설정 화면**: 리포 선택·브랜치·경로 제거(또는 관리자 전용 읽기 표시), 인앱 알림 추가 (A3, A4, B3)
- [ ] **녹음 화면**: 회의 일시 입력 필드 추가 (A5)
- [ ] **회의록 상세**: 읽기/편집 모드 토글 + 인라인 에디터 + 저장→PR 동기화 표현 (B2)
- [ ] **공통(Layout)**: 종 아이콘(인앱 알림 뱃지), 단일 리포 표시 정리 (B3, D3)

> 상태머신 보관완료(D1)·Slack 연동 방식(D2)은 Stage 3/4에서 별도 확정.
